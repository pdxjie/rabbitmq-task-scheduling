# TaskFlow 前端 UI 设计方案

## 一、设计理念

### 1.1 核心原则

- **现代化**：采用深色模式为主，科技感强
- **简洁清晰**：信息层次分明，避免冗余
- **实时响应**：WebSocket 实时更新，流畅动画
- **易用性**：操作流程简单，符合直觉

### 1.2 设计风格参考

- **Vercel Dashboard**：简洁、现代、深色模式
- **Linear**：流畅动画、细腻交互
- **GitHub Actions**：工作流可视化
- **Grafana**：监控大盘、图表展示

```typescript
  const ws = new WebSocket(`ws://localhost:8080/ws/monitor/${clientId}`);
  
  ws.onmessage = (event) => {
    const message = JSON.parse(event.data);
    
    if (message.type === 'system_metrics') {
      setMetrics(message.data);  // 更新监控数据
    }
  };
  
  return () => ws.close();
}, []);
```
